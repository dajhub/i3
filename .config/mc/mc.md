# Midnight Commander (MC) Keyboard Shortcuts Cheat Sheet

## Panel Management
* **`Tab`**: Switch focus between the left and right panels.
* **`Ctrl + u`**: Swap the left and right panels.
* **`Ctrl + r`**: Refresh the currently active panel.
* **`Alt + o`**: Open the selected directory in the other panel.
* **`Alt + i`**: Make the inactive panel mirror the active panel's directory.
* **`.`** (Period): Show or hide hidden files (starting with `.`).

## File & Directory Operations
* **`F3`**: View the selected file.
* **`F4`**: Edit the selected file.
* **`F5`**: Copy the selected file/directory.
* **`F6`**: Move or rename the selected file/directory.
* **`F7`**: Create a new directory.
* **`F8`**: Delete the selected file/directory.
* **`Shift + F6`**: Rename a file/directory.
* **`Ctrl + x c`**: Open the **chmod** (permissions) dialog for marked files.
* **`Ctrl + x o`**: Open the **chown** (ownership) dialog.
* **`Ctrl + space`**: Check the size of the highlighted directory.

## Navigation & Searching
* **`Enter`**: Open a directory or execute a program.
* **`Alt + c`**: Open a **Quick CD** prompt to easily jump to paths.
* **`Alt + s`**: Start an incremental quick search (just start typing to filter).
* **`Alt + ?`**: Open the find/search file dialog.
* **`Alt + Shift + h`**: Open your directory **history** list.

## Selection
* **`Insert`**: Select or deselect the current file/directory.
* **`+` (Plus)**: Bring up a regex prompt to **select multiple files** at once.
* **`\` (Backslash)**: Deselect all files.
* **`*`**: Invert the current file selection.

## Menus & System
* **`F9`**: Jump focus to the top menu bar.
* **`F10`**: Exit Midnight Commander.
* **`Ctrl + o`**: Hide panels temporarily to view the underlying shell output (press again to return).
