# Lazyvim Cheat Sheet
---

## General
| Description                           | Commands                                                           |
|---------------------------------------|--------------------------------------------------------------------|
| Open terminal                         | <space> ft                                                         |
| Insert character at beginning of line | CTRl + v ; j/k move down/up ; SHIFT + I and type character(s) ; ESC|


## Buffers

| Description                           | Commands                                                           |
|---------------------------------------|--------------------------------------------------------------------|
| Close buffer                          | <space> bd                                                         |
| Moving between buffers                | SHIFT + H (left) ; SHIFT + L (right)                               |
